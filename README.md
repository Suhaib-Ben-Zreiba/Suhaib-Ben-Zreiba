## Projects

**[AlBayan School Management Platform](https://albayanschool.online)** — production registration, tuition-payment, and attendance system for a real school, in active daily use. Transactional QR/payment-code check-in with idempotent writes, automated e-transfer reconciliation against the Gmail API, Vitest coverage on the edge cases. `Next.js` `TypeScript` `Firestore` — source private (student financial data), site linked above.

**[student-record-analyzer](https://github.com/Suhaib-Ben-Zreiba/student-record-analyzer)** — C program parsing and validating structured student records from file input, with search, sort, and summary statistics over dynamically allocated data. `C`

**[student-records-system](https://github.com/Suhaib-Ben-Zreiba/student-records-system)** — layered Java CLI application (model / service / storage) with full CRUD and CSV-backed persistence. `Java`

**[hex-data-parser](https://github.com/Suhaib-Ben-Zreiba/hex-data-parser)** — parses raw hexadecimal byte streams and maps byte ranges to named register fields via a JSON register map. `Python`

**[course-file-organizer](https://github.com/Suhaib-Ben-Zreiba/course-file-organizer)** — normalizes inconsistent filenames and sorts files into type-based directories, with safe duplicate handling. `Python`

Digital design coursework — RTL/testbenches in Vivado, a pipelined ARM-style processor in Logisim, an FSM-driven SystemVerilog calculator with testbenches — exists locally and is being pushed as standalone repos.
